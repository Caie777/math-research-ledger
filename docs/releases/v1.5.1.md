# MathResearch Ledger v1.5.1

Released 2026-11-27. This patch fixes DSH Host installation and runtime path
portability. The eleven MCP tools, Agent workspace binding, relative activation
pointer, and existing research data and authority semantics are unchanged.

## What changed

- DSH can install the public `dsh-math-research-ledger-host-1.5.1.tgz` as-is. It
  contains no rendered runtime path and replaces the old Host preparation script.
- The Host resolves Python on activation, using an optional absolute `python`
  Profile override or the Host's PATH. An invalid override is not silently ignored.
  Missing or unusable runtimes report `MRL_RUNTIME_UNAVAILABLE` before activation
  writes. Workspaces without a pointer do not start Python unless the user opts in.
- Python remains a separate environment. The manual single-workspace fallback
  remains a template and is not the recommended Host installation.

## Upgrade and migrate

1. Remove the old Host package from the target DSH Profile, then install and enable
   `dsh-math-research-ledger-host-1.5.1.tgz` in DSH Plugins. Use the Host tarball,
   not the fallback tarball; remove the fallback too if it was installed instead.
2. In the intended Python environment, install
   `math_research_ledger-1.5.1-py3-none-any.whl[mcp]` with that Python's `-m pip`.
   Rebuild the venv at its new location if it or its base Python was moved. Put
   its `Scripts`/`bin` first on the Host PATH, or update the native Profile `python`
   override. Clear any stale override if using PATH.
3. Restart DSH and open a new Agent at the same research root. Leave the research
   data and any valid `.math-research-ledger-link` as they are. An existing valid
   pointer does not require running the enable command again.

See the [Host installation and migration guide](https://github.com/Caie777/math-research-ledger/blob/v1.5.1/integrations/deepseek-harness/host-plugin/README.md)
for configuration, diagnostics, and uninstall.

## Artifacts and verification

This GitHub Release includes the Python wheel and sdist, Host and fallback npm
package tarballs, and `SHA256SUMS`. No packages are published to PyPI or npm.

Reused portability-fix results: 39 targeted pytest checks and 24 Node path tests
passed; three Node symlink cases were skipped because the Windows environment
could not create those links. Targeted Ruff check/format and Git whitespace
checks passed. The final build checks release versions, archive contents, and asset
hashes. No full pytest, DSH live acceptance, real Profile change, or real Ledger
access was performed for this release.
